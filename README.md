# Interactive mocks

Interactive UX concepts for Red Hat Hybrid Cloud Console workflows.

## Live patch status concepts

The current prototype explores four ways to communicate system-specific live
patch (kpatch) status in Insights Vulnerability:

1. A dedicated column on the CVE detail page
2. Status attached to the system name
3. An eligibility summary with progressive disclosure
4. Live patch availability on a system details page

Open `index.html` directly in a browser. The mock is self-contained and uses
synthetic system and vulnerability data.
