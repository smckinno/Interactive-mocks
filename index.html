How live patching works

Product implication: “A live patch exists for this CVE” is not enough. The useful status depends on the CVE, the system’s running kernel, and whether live patching is configured.

What it does

Linux live patching loads replacement kernel functions and safely redirects running tasks to the updated code. This mitigates supported kernel vulnerabilities without stopping workloads for an immediate reboot.

What users still need to know

  • Not every kernel fix can be safely converted into a live patch.
  • Live patch packages are tied to supported kernel revisions and are commonly cumulative.
  • A protected system is not in an emergency state, but regular kernel updates and planned reboots remain part of maintenance.
